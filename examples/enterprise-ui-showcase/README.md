# Craft Enterprise UI Showcase — Phase 1

Run with Craft 0.1.50:

```powershell
craft package lock
craft check
craft run
```

The Dashboard, Components, and Navigation pages exercise Phase 1 tokens, layout, buttons, badges, sidebar hover, and tabs. Forms, Data, Dialogs, and Settings are explicit placeholders for later phases. Use the keyboard Tab and Enter/Space to inspect native button focus and activation. Resize the window and try a different Windows display scale.
