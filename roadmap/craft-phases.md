# นิยาม Phase ของ Craft

โครงการกำหนด **สอง Phase เท่านั้น**: Phase 1 สำหรับการพัฒนา Craft และ Phase 2 สำหรับทำให้พร้อมใช้งานจริง.

นิยามปัจจุบัน: **Craft อยู่ใน Phase 1** ซึ่งรวมภาษา, Runtime, standard library, package, ตัวอย่าง, การตรวจรับ และการแจกจ่ายไว้ในรอบพัฒนาเดียวกัน. งานเหล่านี้แยกเป็นหัวข้อในแต่ละ revision เพื่อให้เห็นความรับผิดชอบและผลตรวจรับของแต่ละส่วน.

- Rev.24 / Craft `0.1.24`: เพิ่ม Canvas/paint ใน Runtime และเริ่ม `packages/gui` `0.2.1` เป็นหัวข้อ package ใน Phase 1.
- Rev.25 / Craft `0.1.25`: เพิ่ม viewport/style/Canvas targets ใน Runtime และปรับ `packages/gui` เป็น `0.2.2` ใน Phase 1 เดียวกัน.

เลข `0.2.1`/`0.2.2` เป็นเวอร์ชันของ GUI dependency ใน `craft.toml` เท่านั้น. `craft version` และ Windows Setup ยังคงใช้ Craft `0.1.25`. Phase ไม่ใช่ตัวกำหนดเวอร์ชันหรือคำรับรองว่าใช้งานจริงพร้อมแล้ว. การออก Craft V1.00 เป็นการตัดสินใจของเจ้าของโครงการ.

แผน package รุ่น 0.2.1/0.2.2 ย้ายเข้า `roadmap/phase1/packages/` แล้ว. อ้าง [แผน Phase 1 Rev.24](phase1/craft-phase1-rev24.md), [Rev.25](phase1/craft-phase1-rev25.md) และ [ตารางหัวข้อพัฒนา](workstreams.md) สำหรับนิยามปัจจุบัน.

## Phase 2 — ความพร้อมใช้งานจริง

Phase 2 จะเริ่มเมื่อเจ้าของโครงการตัดสินใจเปลี่ยนจุดเน้นจากการสร้างความสามารถ ไปสู่การพิสูจน์และปรับคุณภาพ Craft กับแอปที่ใช้งานจริง. งานหลักคือความเสถียร, compatibility และ migration, diagnostics, security, accessibility, ประสิทธิภาพของ GUI ภายใต้โหลด, การทำงานของ UI ร่วมกับ HTTP และการติดตั้ง/แจกจ่ายแอปให้ผู้ใช้เปิดได้สะดวก. ให้กำหนด workload, ขอบเขต OS และเกณฑ์ตรวจรับที่วัดซ้ำได้ก่อนสรุปว่าพร้อมใช้งาน.

Phase 2 ยังไม่ได้เริ่ม และไม่ใช่ชื่อเวอร์ชันของ package. การเข้าสู่ Phase 2 **ไม่ประกาศ V1.00 โดยอัตโนมัติ**; เจ้าของโครงการตัดสินใจเรื่อง V1.00 แยกต่างหาก.
