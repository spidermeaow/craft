# Archived Phase 1 package prototypes

These sources are historical snapshots from Craft 0.1.20. The GUI package resumed in Phase 1 Rev.24 at `packages/gui` as version 0.2.1 and has since advanced to 0.2.8. The API framework remains paused. Archived sources are not included in the Windows installer or the active example dependency graph.

`examples/api-server` preserves the original framework-based example; `templates/gui` preserves the GUI package template previously embedded in `craft.exe`. The active examples use `std.ui` and `std.http` directly. The package manager itself remains active.

Do not assume archived sources work unchanged with future runtime revisions. Restore them deliberately as Phase 2 work, with updated manifests, docs, and tests.
