# Changelog

## 0.2.1

- Highlight Rev.5 database native types and add a database connection snippet (requires Craft 0.1.5).

## 0.2.0

- Rev.4 import/export highlighting, Fn/Bytes/Context/HTTP types.
- New import4, fn4 and http4 snippets (Craft CLI 0.1.4 required).
- Preserves the extension ID and both themes; replaces language support0.1.0.
- Tokenizer cases prepared for the new syntax; user-run verification pending.

## 0.1.0

- Craft registration, TextMate grammar, editing configuration and snippets.
- Original Craft Dark and Craft Light palettes; existing themes remain selectable.
- Supports Rev.2 syntax and Rev.3 Task/Timer type names. `task3`/`timer3` snippets require CLI 0.1.3.
- Declarative extension: no activation code, workspace execution or telemetry.
